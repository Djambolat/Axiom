Методы массива

Существуют два основных вида методов. Трансформирующие и нетрансформирующие Трансформирующие методы (Мутирующие) Эти методы изменяют сам исходный массив, на котором они были вызваны. Они работают «на месте» (in-place). push() — добавляет элементы в конец. pop() — удаляет последний элемент. shift() — удаляет первый элемент. unshift() — добавляет элементы в начало. splice() — вырезает, удаляет или вставляет элементы в любое место массива. reverse() — разворачивает массив задом наперед. sort() — сортирует элементы массива.

Пример:


            const fruits = ['яблоко', 'банан'];
            fruits.push('апельсин'); // Изменил исходный массив fruits
            console.log(fruits); // ['яблоко', 'банан', 'апельсин']
Немутирующие методы (Безопасные) Эти методы НЕ трогают исходный массив. Вместо этого они возвращают совершенно новый массив или другое итоговое значение (число, строку, логическое значение). map() — трансформирует каждый элемент и возвращает новый массив той же длины. filter() — отбирает элементы по условию и возвращает новый массив. reduce() — сжимает массив до одного значения (как мы разбирали выше). slice() — копирует часть массива и возвращает её в виде нового массива. concat() — объединяет два массива в новый третий массив. join() / toString() — склеивают массив в строку. find() / findIndex() — ищут элемент или его индекс, возвращают значение/число. includes() / every() / some() — проверяют условия и возвращают true или false.

Пример:


            const numbers = [1,2,3];
            const doubled = numbers.map(num => num * 2); // Создал новый массив
            console.log(numbers); // [1, 2, 3] — исходный массив остался цел!
            console.log(doubled); // [2, 4, 6] — результат в новой переменной

Метод reverse()

Метод reverse() разворачивает массив задом наперёд. от элемент, который был самым первым, становится самым последним, а последний — первым.

Пример:


            const numbers =[1,2,3,4,5];
             // Вызываем метод
            numbers.reverse();
            console.log(numbers); 
            // Результат: [5, 4, 3, 2, 1] — исходный массив ИЗМЕНИЛСЯ!
То есть у нас был массив от 1 до 5 мы мызвали метод reverse и порядок поменялся. Так как сам массив изменился, не сложно догадаться что этот метод является мутирующим

Метод map()

Метод map()— это один из самых популярных и часто используемых методов массивов в JavaScript. Его главная суть: взять один массив, изменить каждый его элемент по определенному правилу и вернуть совершенно новый массив точно такой же длины. Он относится к немутирующим методам. Это значит, что ваш исходный массив останется абсолютно целым и невредимым. давайте разбирать его постепенно. для начала наглядный простой пример. 

            const numbers = [1,2,3,4,5]   //создаем массив чисел
            const newNumbers = numbers.map(number => number * 2)  //создаем новый массив на основе мутации старого
            console.log(newNumbers) //результат нового -  [2,4,6,8,10]
            console.log(numbers) //результат старого не изменился -  [1,2,3,4,5]
таким образом map не изменяет существующий массив. он просто берет каждый элемент старого массива, проводит над ним какие то действия и возвращает этот элемент уже новому массиву давайте разбирать метод map пословно самое первое что трубется вписать в метод - это то как мы назовем элемент массива. в основном это зависит от сущности массива. если массив numbers, то элемент массива - number newArray= numbers.map(number...) далее идет стрелочная функция => newArray= numbers.map(number =>...)
