1. Комментарии

Комментарий — это текст внутри кода, который JavaScript не выполняет. Существует следующие виды коментариев:
  • Однострочный комментарий 
    
                // Это комментарий
                const name = "Тимон";
  • Многострочный комментарий 
    
                /*Это 
                многострочный 
                комментарий*/
    💡 Зачем нужны комментарии?

    Чтобы оставить пояснение для себя или другого разработчика.

2. Типы данных

JavaScript работает с разными типами значений. На начальном этапе нам особенно важно понимать:

  • Number — числа
  • String — строки
  • Boolean — true или false
  • Undefined — значение не определено
  • null — отсутствие значения
  • Object — объекты, массивы и другие конструкции 

            Пример:
            const age = 20;
            const name = "Тимон";
            const isStudent = true;

3. typeof

Оператор typeof позволяет узнать тип значения.


              const age = 20;
              console.log(typeof age);
              // "number"

              const name = "Тимон";
              console.log(typeof name);
              // "string"
⚠️ Интересный момент

У typeof null результатом будет "object". Это историческая особенность JavaScript.

4. Переменные

Переменная — это имя (контейнер), под которым мы можем хранить значение. 


            let name = "Тимон";

Здесь:

  • let — ключевое слово;
  • name — имя переменной;
  • = — оператор присваивания;
  • "Тимон" — значение.

let

Используем, если значение переменной может измениться.


              let age = 20;
              age = 21;

const

Используем, если переменную не планируем переприсваивать.


              const name = "Тимон";

var

Старый способ объявления переменных. В современном коде обычно используют let и const.

5. Преобразование типов

JavaScript может автоматически преобразовывать значения одного типа в другой. 


              Пример
              "5" + 2; // "52"

При использовании + со строкой происходит объединение строк — конкатенация. 


              "5" - 2; // 3

В этом случае JavaScript преобразует строку "5" в число.

Явное преобразование

Number("123");
              // 123
              String(123); // "123"
              Boolean(1); // true

6. Операторы сравнения

Не путай оператор присваивания = с оператором сравнения ===. 

const age = 20;

Здесь = присваивает значение переменной.


              age === 20; // true

=== сравнивает значение и тип.


              20 === "20"; // false
💡 Совет

В современном JavaScript обычно предпочитают строгое сравнение ===.

7. Строки и шаблонные строки

Строки можно объединять с помощью оператора +. 


              const name = "Тимон";
              const age = 20;
              console.log("Привет, меня зовут " + name +", мне " + age + " лет.");

Шаблонные строки

Более удобный вариант — использовать обратные кавычки и интерполяцию. 


              const name = "Тимон";
              const age = 20;
              console.log(`Привет, меня зовут ${name}, мне ${age} лет.`);

8. Функции

Функция — это блок кода, который можно вызвать, когда он понадобится. 


              function sayHello() {
               console.log("Привет!");}
              sayHello();

Сначала мы объявили функцию, затем вызвали её.

Параметры и аргументы


              function sayHello(name) {
              console.log(`Привет, ${name}!`);}
              sayHello("Тимон");
  • name — параметр;
  • "Тимон" — аргумент.

return

return возвращает значение из функции. 


              function sum(a, b) {
              return a + b;}
              const result = sum(5, 10);
              console.log(result); // 15
⚠️ Не путай

console.log() выводит информацию в консоль, а return возвращает значение из функции.

9. Стрелочные функции

Стрелочная функция позволяет записывать функции более компактно. 


              const sum = (a, b) => {
              return a + b;};

Если функция состоит из одного выражения, её можно записать ещё короче: 

const sum = (a, b) => a + b;

10. Условия

Условные конструкции позволяют выполнять разные действия в зависимости от ситуации. 

const age = 20;
              if (age >= 18) {
              console.log("Доступ разрешён");
              } else {
              console.log("Доступ запрещён");}

Несколько условий

if (age < 18) {
              console.log("Несовершеннолетний");
              } else if (age === 18) {
              console.log("Только исполнилось 18");
              } else {
              console.log("Совершеннолетний");}

Тернарный оператор

Простое условие иногда можно записать короче:

const access = age >= 18 ? "Разрешён": "Запрещён";
