Немутирующие методы (Безопасные) Эти методы НЕ трогают исходный массив. Вместо этого они возвращают совершенно новый массив или другое итоговое значение (число, строку, логическое значение). map() — трансформирует каждый элемент и возвращает новый массив той же длины. filter() — отбирает элементы по условию и возвращает новый массив. reduce() — сжимает массив до одного значения (как мы разбирали выше). slice() — копирует часть массива и возвращает её в виде нового массива. concat() — объединяет два массива в новый третий массив. join() / toString() — склеивают массив в строку. find() / findIndex() — ищут элемент или его индекс, возвращают значение/число. includes() / every() / some() — проверяют условия и возвращают true или false. Пример:

const numbers = [1,2,3]; const doubled = numbers.map(num => num * 2); // Создал новый массив console.log(numbers); // [1, 2, 3] — исходный массив остался цел! console.log(doubled); // [2, 4, 6] — результат в новой переменной

Метод reverse()

Метод reverse() разворачивает массив задом наперёд. Тот элемент, который был самым первым, становится самым последним, а последний — первым. Пример:

const numbers =[1,2,3,4,5]; // Вызываем метод numbers.reverse(); console.log(numbers); // Результат: [5, 4, 3, 2, 1] — исходный массив ИЗМЕНИЛСЯ!

То есть у нас был массив от 1 до 5 мы мызвали метод reverse и порядок поменялся. Так как сам массив изменился, не сложно догадаться что этот метот является мутирующим

Метод map()

Метод map()— это один из самых популярных и часто используемых методов массивов в JavaScript. Его главная суть: взять один массив, изменить каждый его элемент по определенному правилу и вернуть совершенно новый массив точно такой же длины. Он относится к немутирующим методам. Это значит, что ваш исходный массив останется абсолютно целым и невредимым. давайте разбирать его постепенно. для начала наглядный простой пример.

const numbers = [1,2,3,4,5] //создаем массив чисел const newNumbers = numbers.map(number => number * 2) //создаем новый массив на основе мутации старого console.log(newNumbers) //результат нового - [2,4,6,8,10] console.log(numbers) //результат старого не изменился - [1,2,3,4,5]

таким образом map не изменяет существующий массив. он просто берет каждый элемент старого массива, проводит над ним какие то действия и возвращает этот элемент уже новому массиву давайте разбирать метод map пословно самое первое что трубется вписать в метод - это то как мы назовем элемент массива. в основном это зависит от сущности массива. если массив numbers, то элемент массива - number newArray= numbers.map(number...) далее идет стрелочная функция => newArray= numbers.map(number =>...) Затем уже идет действие которое мы хотим провернуть с элементом. newArray= numbers.map(number => number * 3) //каждый элемент массива умножает на 3 в итоге если в массиве numbers было [1,2,3,4,5] то в новом массиве станет [3,6,9,12,15] давайте теперь сделаем что то поинтереснее. Допустим у меня есть массив цен, и я хочу сделать новый массив в котором на против цен будет -Дорого или -Дешево. пускай для нас 100 это уже дорого а то что ниже это дешево

const prices = [120, 90, 76, 200] //создаем массив цен const statusOfPrices = prices.map(price => if(price >= 100){ //Если цена больше или равна 100: price+"-Дорого"} // присоединить к цене выражение -Дорого else{ //Иначе: price+"-Дешево"}) // присоединить к цене выражение -Дешево

слишком много строк. поэтому более читабельнее будет использовать тернарный оператор

const prices = [120, 90, 76, 200] //создаем массив цен const statusOfPrices = prices.map(price => price >= 100? price+"-Дорого" : price+"-Дешево") // до знака(?) это логическое ЕСЛИ, после(?) - это логическое ТО, после(:) - Это логическое ИНАЧЕ console.log(statusOfPrices) // результат: [120-Дорого, 90-Дешево, 76-Дешево, 200-Дорого]

Обратите внимание до стрелочной функции мы записали только один параметр - price, который несет в себе значение элемента массива Но помимо него можно внести еще два параметра, индекс и массив, но мы будем разбирать только индекс

// Создаем обычный массив из четырех чисел const numbers =[10, 20, 30, 40]; // Умножаем каждое число (num) на его индекс (index) const multipliedByIndex = numbers.map((num, index) => num * index); console.log(multipliedByIndex); // Результат в консоли: [0, 20, 60, 120]

Как это сработало в памяти по шагам: Индекс 0: число 10 умножается на 0 \ получаем 0 Индекс 1: число 20 умножается на 1 \получаем 20 Индекс 2: число 30 умножается на 2 \ получаем 60 Индекс 3: число 40 умножается на 3 \ получаем 120 Примечание: Индекс-порядковый номер элемента массива. Индексация начинается с нуля Обратите внимание на параметры (num,index). как бы мы не назвали первый параметр, JS будет его рассматривать как имя для содержания элемента массива. как бы мы не назвали второй параметр, JS будет рассматривать его как имя для индекса элемента массива. если в методе map мы используем один параметр то его не нужно оборачивать в скобки, а если больше то параметры нужно обернуть в скобки // map.(num => ...) // map.((num, index) =>...)
